# 视觉方向 — “坐标轴 / 规格表”

> 状态：draft（2026-11-25）
> 上游：[brief.md](brief.md)、[information-architecture.md](information-architecture.md)
> 下接：[tokens.md](tokens.md)
> 这是一个**待验证的方向假设**，不是最终皮肤，也不是品牌方案。

## 1. 一句话

把工作台做成一台**测量 Ontology 的仪器**：浅色轴轨给出位置，规格表式的对象类型页给出结构，等宽标识符给出精度，一个深青信号色标记当前路径。装饰退后，信息前置。

## 2. 为什么不是现在这样

现状（见 Stage 1 截图）是典型的通用后台：

- 深色渐变侧栏 + 靛蓝 `#5b5bd6` + 圆角白卡 + 柔和阴影；
- 每页一枚全大写 eyebrow（“Stage 1 · 核心工作台”）；
- 顶栏与页头重复标题；
- 表格首列 UUID 折成两行，右侧详情面板大面积空置。

它的问题不是“不好看”，而是**换成任何 B2B 产品都成立**。它没有回答这个产品独有的问题：类型、属性、关系、实例、数据集、查询之间是什么关系。

## 3. 母题：轴与规格表

产品名“元轴”提供了一个可用的结构隐喻，但不要做成蓝图底纹或坐标网格插画。具体落点只有三个：

1. **轴轨**：左侧导航右缘一条 1px 轴线，分组标签带短刻度。它编码层级（分组边界），不是装饰。
2. **规格表头**：对象类型页的头部像一张规格表——显示名、标识符、描述、主键、属性/关系计数、更新时间，一行读完。
3. **检查器**：选中属性、关系或实例时，右侧 360px 面板就地展开。用户始终知道“我在哪、我选中了什么”。

记忆点只花在“轴轨 + hub 脊柱”上；其余保持安静。

## 4. 色彩

### 核心层（6 个）

| Token | 值 | 用途 |
| --- | --- | --- |
| `canvas` | `#F4F5F3` | 页面底色，略偏绿的暖灰，不是纯灰 |
| `surface` | `#FFFFFF` | 表格、面板、模态 |
| `sunken` | `#ECEEEB` | 表头、只读区、代码块底 |
| `ink` | `#15181A` | 主文本，中性近黑，不偏蓝 |
| `ink-secondary` | `#4A5153` | 次要文本、正文说明 |
| `muted` | `#5F6669` | 元信息、占位、禁用文本 |

边框：`#E2E4E1`（常规）、`#CDD1CC`（强调分隔）。  
信号：`#0E6B5C`（主操作、选中、焦点）、`#0A564A`（hover）、`#E3F0EC`（选中底）。

### 功能色（只用于编码，不用于装饰）

| 语义 | 值 | 用法 |
| --- | --- | --- |
| 数据类型 · 数值 | `#A15C00` | schema 表中的 6px 方块 + 文本 |
| 数据类型 · 布尔 | `#6B4C8A` | 同上 |
| 数据类型 · 时间 | `#2F5FA8` | 同上 |
| 数据类型 · 文本 | `#4A5153` | 同上，不额外着色 |
| 成功 | `#1F7A4D` | 8px 圆点 + 文本 |
| 警告 | `#8A5A00` | 同上 |
| 危险 | `#B3261E` | 同上 |
| 信息 | `#245C8A` | 同上 |

规则：

- 信号色**只**给“当前路径”和“可执行动作”；不得用于状态、数据类型或图表系列。
- 状态一律“圆点 + 文字”，类型一律“小方块/字母 + 文字”；不使用彩色胶囊 badge。
- 一个视图里最多出现两种功能色；出现第三种时先问它是否真的需要。
- 不使用渐变、发光、彩色阴影。

## 5. 字体

| 角色 | 字体 | 说明 |
| --- | --- | --- |
| 正文/界面 | IBM Plex Sans | 开源 OFL；技术感但不过分风格化 |
| 中文 | IBM Plex Sans SC（回退 PingFang SC / Noto Sans SC） | 若内网字体预算不允许，直接回退系统字体，比例尺不变 |
| 标识符/数字 | IBM Plex Mono | 仅用于 `snake_case`、UUID、SQL、版本号、计数 |

比例尺（7 级）：

| Token | 字号 / 行高 | 用途 |
| --- | --- | --- |
| `text-xs` | 12 / 1.35 | 元信息、表头、辅助说明 |
| `text-sm` | 13 / 1.35 | 表格、密集 UI |
| `text-base` | 14 / 1.5 | 正文、表单 |
| `text-md` | 16 / 1.3 | 卡片/区块标题 |
| `text-lg` | 20 / 1.25 | 页面内分区标题 |
| `text-xl` | 26 / 1.2 | 页面标题 |
| `text-2xl` | 32 / 1.1 | 仅登录页等展示场景 |

规则：

- 字重只用 400 / 500 / 600；不用 700 以上。
- 数字比较场景一律 `font-variant-numeric: tabular-nums`。
- 中文不加字距、不做全大写；全大写只用于缩写（UUID、SQL、OIDC）。
- 不再使用“标题上方的小号全大写 eyebrow”；阶段信息移到关于/帮助，不进入每页。
- 正文每行不超过约 40 个汉字（≈80 个拉丁字符），说明文字最大宽度 640px。

## 6. 布局语法

| 项 | 值 | 说明 |
| --- | --- | --- |
| 轴轨宽 | 224px；折叠 64px | 浅色，右侧 1px 轴线 |
| 检查器宽 | 360px | 1080 以下改为抽屉 |
| 内容最大宽 | 1440px | 页面左右 padding 32px |
| 栅格 | 12 列 / 24px gutter | 只在大屏使用；表格不受栅格约束 |
| 表格行高 | 40px（密集）/ 48px（舒适） | 默认 40；表头 36 |
| 区块间距 | 32px；组内 16px | 用间距和 1px 规则分隔，不叠卡片阴影 |
| 圆角 | 4px（控件）/ 8px（面板）/ 全圆（头像、状态点） | 取消 12/18 |
| 阴影 | 仅浮层 | 卡片只用 1px 边框，不投影 |

卡片不是默认容器。只有当一个区块确实需要独立边界（如模态、检查器、表单分组）时才使用；列表和详情用整页布局与分隔线组织。

## 7. 记号系统

- **标识符**：`IBM Plex Mono` 12px，`customer_id`、`0190f3…`。表格中单行、末尾省略、悬停显示全值、点击复制；禁止在表格中折成两行。
- **版本**：`v3`，tabular，muted；不做胶囊。
- **计数**：tabular，右对齐；单位与数字之间不加空格（`4 个属性`）。
- **关系**：`Customer → Order`。箭头只用于真实的方向关系，不用于按钮文案（不写“保存 →”）。
- **状态**：8px 圆点 + 文本；不用整块彩色背景。
- **数据类型**：6px 方块 + 类型名；文本类型不着色。
- **元信息**：用换行或带标签的键值对，不用“A · B · C”式的中点串。
- **编号**：只有内容本身是序列（步骤、版本、层级）时才编号；不用 01/02/03 装饰区块。

## 8. 动效

- 只做状态反馈：hover/focus 120ms，面板展开 180ms，`ease-out`。
- 不做页面入场、逐块上浮、卡片 hover 位移。
- `prefers-reduced-motion: reduce` 时全部降为无动画。
- 加载用骨架屏，不用旋转图标占满版面（短按钮操作除外）。

## 9. 自检：哪些是通用默认，已刻意改掉

初稿与本方向的对照：

| 通用默认 | 本方向的处理 |
| --- | --- |
| 奶油底 + 衬线大标题 + 陶土色 | 拒绝。使用中性偏绿的浅灰底 + 无衬线 + 深青信号 |
| 近黑底 + 酸性绿/朱红单一强调 | 拒绝。浅色工作区，深色只用于代码块 |
| 报纸式细线 + 零圆角 + 密栏 | 拒绝。保留 4/8px 圆角与舒适行高 |
| SaaS 卡片套件（同一圆角、同一阴影） | 拒绝。取消卡片阴影，按内容分组，不用统一卡片网格 |
| 每页全大写 eyebrow / 中点元信息 / 箭头按钮 | 拒绝。阶段信息移出页面；元信息用键值或换行；箭头只表方向 |
| 过渡色近黑 `#0B0B0B` | 拒绝。使用中性 `#15181A` |

仍需警惕：浅灰 + 深青本身也是常见组合。本方向的辨识度来自**结构**（轴轨、hub 脊柱、检查器、规格表头）和**记号**（标识符优先、状态点、类型方块），不是色相。如果去掉结构只留配色，它会退回通用后台——这是评审时的判断标准。

## 10. 如何验证

1. 先做一版静态对比：只改壳层 + 对象类型 hub，不迁移全部页面。
2. 与另一版“浅色但更常规”的方案并排，用同一组任务做 5 秒测试与 3 人任务测试。
3. 截图基线：1440×900 与 1280×800；记录改造前后。
4. 检查：对比度（见 [tokens.md](tokens.md)）、键盘路径、焦点可见、200 属性与超长名称下的布局。
5. 如果用户无法在 5 秒内说出“当前项目 / 当前类型 / 下一步”，先改 IA，不要改配色。

## 11. 风险

- IBM Plex Sans SC 体积较大：必须子集化自托管；否则回退系统字体，不引入阻塞渲染的第三方 CDN。
- 浅色轴轨可能弱化导航存在感：用 1px 轴线、分组标签和选中态补偿；若测试失败，再考虑加深轴轨而不是回到渐变。
- 取消卡片阴影可能让层级变平：用间距、标题层级和 1px 分隔建立层级，不靠阴影。
- 高密度表格对空态和错误态要求更高：状态契约必须先于视觉实现。
