```

### 5. 负向/正向用例：chart values 的 tag 可被解析

```
$ python3 scripts/deps.py lock   # 该组件条目出现 tag: "26.0"
$ python3 scripts/deps.py check --verbose

验证点：tag 进入锁文件、进入浮动 tag 判定；恢复后 `git status` 干净。
