# 依赖版本基线（2026-11-23）

- 方法：`python3 scripts/deps.py lock` 抽取部署资产中的全部镜像引用；`scripts/deps.py audit`
  查询 Docker Hub / Quay 上游 tag 与 endoflife.date EOL。原始审计表见
  `2026-11-23-deps-audit.md`，同一目录。
- 口径：`当前` 取仓库中带 tag 的引用；Helm values 只有 `repository + digest`，无 tag，
  因此记为「无 tag」。`上游最新` 是 registry 返回的 tag 中的最大版本号，不含 rc/beta/nightly。
- 本文件只记录基线事实，不等于升级决定；升级按 tier 走 change 或 Fast Track。

## 4. Helm（`deploy/helm/`）

全部 21 个组件只有 `repository + digest`，无 tag；`deploy/README.md` 自述 digest 为
deterministic placeholder。因此**无法从 Helm values 判定实际版本**，本基线不对其做版本结论。

| Chart | 组件 |

| `ontoaxis-platform` | postgres、keycloak、openfga、valkey、seaweedfs |
| `ontoaxis-data` | kafka、debezium、apicurio、kestra、temporal、trino、nessie |

| `ontoaxis-app` | ontoaxis-core、web、meilisearch、ontoaxis-search |

`helm-placeholder-digests`）。

## 5. 未覆盖范围（不在本 change 基线内）

- `go.mod` / `go.sum` 与 `web/package.json` 的库版本：本工具只覆盖镜像引用；
  库版本由 Renovate 的 gomod/npm 管理器接管，当前仓库的过旧情况见 Stage 2 盘点记录。
- GitHub Actions 的 `uses:` 版本：仍是 `@vN` 浮动 tag，`review_by: 2027-01-31`。
- 集群侧工具（kubectl、kind、Argo CD CLI）由 `deploy/README.md` 记录，未纳入镜像门禁。

## 6. 基线结论

1. 两个浮动 `latest` 已在本 change 消除（Trino、buf），并有 `deps-check` 防回归。
2. P0 中版本落后的有：PostgreSQL（major）、Keycloak、Trino 之外的 Traefik、Meilisearch、
   Temporal、Prometheus、Alertmanager、OTel Collector；均需按 change 排期，不在本 change 顺手升级。
3. P0 已达标：Kestra 2.0.12（LTS）、OpenFGA 1.23.0、Trino 484。
4. Jaeger 不是「落后一个 minor」，而是 v1 已 EOL，必须整体迁移到 v2，单独立项。
5. Helm 占位 digest 是当前最大的不可审计面；例外到期（2026-12-31）必须解决。
