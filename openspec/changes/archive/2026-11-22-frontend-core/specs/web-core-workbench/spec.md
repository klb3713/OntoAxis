## Purpose

定义 OntoAxis 前端核心工作台在浏览器中必须提供的可观察行为，作为 Stage 1 登录、项目、Ontology、对象、数据集与查询六条核心路径，以及后续真实后端接入时页面、认证与错误处理的行为契约。

## ADDED Requirements

### Requirement: 受保护路由与会话

系统 SHALL 在未认证时阻止访问工作台核心页面，并在认证成功后回到用户原本请求的页面；退出登录 MUST 清除本地会话并回到登录页。

#### Scenario: 未认证访问核心页面

- **WHEN** 未建立会话的用户直接访问 Projects、Ontology、对象浏览、数据集或查询页面
- **THEN** 系统重定向到登录页，且不渲染受保护页面内容

#### Scenario: 登录后返回原页面

- **WHEN** 用户在访问受保护页面时被重定向到登录页并完成登录
- **THEN** 系统进入该受保护页面，而不是固定跳转到首页

#### Scenario: 退出登录

- **WHEN** 已登录用户选择退出登录
- **THEN** 系统清除会话、回到登录页，再次访问受保护页面仍被重定向

### Requirement: 登录适配模式

系统 SHALL 支持本地 mock 登录与企业 OIDC 登录两种可配置模式；OIDC 模式 MUST 使用授权码 + PKCE，并校验 state 与 nonce，任何校验失败 MUST 拒绝建立会话。

#### Scenario: mock 登录成功

- **WHEN** 用户在 mock 模式输入有效邮箱与非空密码并提交
- **THEN** 系统建立本地会话并进入工作台

#### Scenario: 无效邮箱被拒绝

- **WHEN** 用户提交格式无效的邮箱
- **THEN** 系统显示可读的校验错误，停留在登录页且不建立会话

#### Scenario: OIDC 回调校验失败

- **WHEN** OIDC 回调缺少有效 state、nonce 或授权码交换失败
- **THEN** 系统拒绝登录、清除临时事务并提示登录失败

### Requirement: 项目资源浏览与创建

系统 SHALL 以分页列表展示项目，并允许按关键词搜索与创建新项目；创建时必须校验项目标识和名称，重复标识 MUST 被拒绝并保留用户输入。

#### Scenario: 浏览与搜索项目

- **WHEN** 用户进入 Projects 页面或输入搜索关键词
- **THEN** 系统显示分页后的项目列表、总数与匹配结果，并支持翻页

#### Scenario: 创建项目成功

- **WHEN** 用户填写合法的项目标识与名称并提交
- **THEN** 系统创建项目、关闭表单并在列表中展示新记录

#### Scenario: 重复项目标识

- **WHEN** 用户提交已存在的项目标识
- **THEN** 系统显示冲突错误、保持表单打开且不产生重复记录

### Requirement: Ontology 模型管理

系统 SHALL 展示对象类型、属性与关系类型，并允许创建对象类型和向对象类型添加属性；属性 MUST 包含名称、显示名称与类型，关系类型 MUST 展示源类型与目标类型。

#### Scenario: 查看对象类型与属性

- **WHEN** 用户进入 Ontology 管理页面并选择对象类型
- **THEN** 系统展示该对象类型的属性列表、主键与更新时间

#### Scenario: 创建对象类型

- **WHEN** 用户填写对象类型标识与显示名称并提交
- **THEN** 系统创建对象类型并使其出现在列表中

#### Scenario: 添加属性

- **WHEN** 用户为对象类型填写属性名、显示名称与类型并提交
- **THEN** 系统保存属性并在该对象类型的属性表中展示

#### Scenario: 查看关系类型

- **WHEN** 用户切换到关系类型视图
- **THEN** 系统展示关系名称、源类型与目标类型，不提供修改入口

### Requirement: 对象浏览

系统 SHALL 允许用户按对象类型过滤对象实例，选择实例后展示其属性、版本、更新时间与原始属性 JSON；无实例时 MUST 显示空态而不是错误。

#### Scenario: 按对象类型浏览实例

- **WHEN** 用户选择某个对象类型
- **THEN** 系统仅展示该类型下的对象实例，并显示关键属性列

#### Scenario: 查看对象详情

- **WHEN** 用户选择一个对象实例
- **THEN** 系统展示该实例的属性、版本、更新时间与原始 JSON

#### Scenario: 对象类型无实例

- **WHEN** 所选对象类型下没有对象实例
- **THEN** 系统显示空态提示，不显示加载失败

### Requirement: 数据集目录与预览

系统 SHALL 以列表展示数据集的名称、格式、负责人与更新时间，并允许查看数据集预览；预览 MUST 展示列结构与样例行，预览失败 MUST 显示可重试错误。

#### Scenario: 浏览数据集

- **WHEN** 用户进入数据集页面
- **THEN** 系统展示分页后的数据集列表及其格式、负责人和更新时间

#### Scenario: 预览数据集

- **WHEN** 用户对某个数据集选择预览
- **THEN** 系统展示该数据集的列结构、样例行、行数与列数

#### Scenario: 预览失败

- **WHEN** 预览请求失败
- **THEN** 系统在预览区域显示错误信息与重试入口，不关闭当前页面

### Requirement: 查询工作台

系统 SHALL 提供 SQL 编辑与执行能力，执行结果 MUST 展示列、行与行数；系统 MUST 拒绝空 SQL 和非 SELECT 语句，并允许保存查询、从已保存查询载入 SQL 以及查看执行计划。

#### Scenario: 执行 SELECT 查询

- **WHEN** 用户输入合法 SELECT 语句并执行
- **THEN** 系统展示结果列、数据行、行数与耗时

#### Scenario: 拒绝空 SQL

- **WHEN** 用户在 SQL 为空时执行查询
- **THEN** 系统提示需要输入 SQL，且不发起执行请求

#### Scenario: 拒绝非 SELECT 语句

- **WHEN** 用户执行非 SELECT 语句
- **THEN** 系统显示仅支持 SELECT 的错误，且不返回结果集

#### Scenario: 保存与载入查询

- **WHEN** 用户将 SQL 保存为命名查询，或从已保存查询中选择一项
- **THEN** 系统持久化该查询并允许其 SQL 重新载入编辑器

#### Scenario: 查看执行计划

- **WHEN** 用户对合法 SQL 请求执行计划
- **THEN** 系统展示可读的查询计划文本

### Requirement: API 运行时适配与错误处理

系统 SHALL 通过可配置的 API 基础路径访问后端，并在客户端边界统一适配列表与实体响应；配置非法时 MUST 拒绝启动而不是静默降级，后端错误 MUST 以统一错误码、消息与请求标识呈现，可重试错误 MUST 提供重试入口。

#### Scenario: 配置 API 基础路径

- **WHEN** 部署方配置 API 基础路径或 mock/真实模式
- **THEN** 所有页面通过同一适配层访问对应数据源，页面代码不感知响应键名差异

#### Scenario: 列表响应键名差异

- **WHEN** 后端分别返回 `data`、`items` 或资源名包裹的列表及分页信息
- **THEN** 页面展示一致的列表、总数与页码

#### Scenario: 非法运行配置

- **WHEN** 运行模式或 OIDC 必填配置非法或缺失
- **THEN** 应用启动失败并给出明确配置错误，不进入 mock 或匿名降级

#### Scenario: 可重试请求失败

- **WHEN** 页面请求返回可重试错误
- **THEN** 系统展示统一错误消息、请求标识与重试入口

### Requirement: 导航与国际化

系统 SHALL 提供到 Projects、Ontology 管理、对象浏览、数据集与查询的持续可见导航，并支持简体中文与英文切换；语言选择 MUST 被持久化，未设置时使用配置的默认语言。

#### Scenario: 导航六条核心路径

- **WHEN** 已登录用户使用侧边导航
- **THEN** 系统进入对应页面并保持工作台布局与当前会话

#### Scenario: 切换语言

- **WHEN** 用户在中文与英文之间切换
- **THEN** 导航、页面标题、表单与状态提示使用所选语言，并在刷新后保持

#### Scenario: 默认语言

- **WHEN** 用户首次访问且未保存语言选择
- **THEN** 系统使用配置的默认语言渲染界面
